# Project vision

Build an original C++ voxel sandbox and use the documented evolution of early Minecraft to inform the order and scope of development. Start with the earliest public release for which sufficient reliable evidence can be established. Record controls, behavior and limitations as historical observations. For each stage, record the choices that carry over as general design ideas and the deliberate differences, including how historical quirks or bugs informed those choices.

Use C++ data structures, explicit resource ownership and measured CPU/GPU work distribution to pursue stable frame times and bounded memory use. Select libraries where they reduce maintenance or improve portability.

Craft++ is independent of Mojang and Microsoft. Use original project code and assets.
