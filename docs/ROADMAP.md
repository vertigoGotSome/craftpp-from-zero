# Roadmap

1. **Historical reference and scope.** Establish the earliest sufficiently documented public reference and agree on the first Craft++ scope. Classic 0.0.11a is the leading historical candidate.
2. **Technical and implementation readiness.** Document the Windows x64 toolchain, decide on rendering after evaluating Vulkan, and define the first original implementation slice. Verify shared CMake presets once a real target exists.
3. **Subsequent stages.** Research the next historical changes and use the evidence to inform an original Craft++ stage. Assign milestone names when the underlying release and scope are established.

These stages carry no release version. See [historical evidence](HISTORICAL_REFERENCE.md) and [status](STATUS.md).
